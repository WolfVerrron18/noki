**Регресс Кирилла (всё закрыто):**
- Главная и услуги: `v-fill` — заливка от указателя (меню, карточки услуг); `v-press` больше не пружинит от простого ухода мыши (это давало «странную тень» и пропадающую подсветку).

- `NokiNumberInput`: был `<label>` → любой тап жал «−». Теперь тап по левой/правой половине = − / + (кнопка этой стороны «нажимается», `playPress`); цена — `currency` (Intl, «2 000 ₽») и прибавки `quick`.

## Подводные камни (уже наступали)

- **Корень экрана — один элемент, комментарий только внутри.** Комментарий перед корнем делает фрагмент → `<Transition mode="out-in">` в `App.vue` зависает, следующий экран пустой.
- **Panel браузера скрыта**: анимации и переходы идут только во время скриншота. Пустой экран сразу после перехода — сначала сделать 1–2 скриншота, потом искать баг. Проверить по-настоящему: `requestAnimationFrame` и `document.visibilityState`.
- **Perl `s|…|…|` в bash**: `|` внутри шаблона ломает замену (испортил `stores/booking.ts`). Использовать `s#…#…#` или Edit/Write.
- **sed с `\$a` в i18n** вставил буквальный `$a`. После правок локалей сверять структуру: `diff <(grep -oE "^ +[a-zA-Z0-9]+:" ru.ts) <(… en.ts)`.
- **Scoped-стили родителя действуют на корень дочернего компонента**: класс `.times` в `WorkHoursEditor` растянул корень `DaySlotsForm`. Корням давать уникальные имена классов.
- **HMR после правки шаблона и скрипта одновременно** иногда оставляет страницу в сломанном состоянии (ложные «Failed to resolve component»). Делать полную перезагрузку (`navigate`).
- Удалять файлы через `rm` песочница не даёт без git; теперь git есть — `git rm`.
- **`<label>` вокруг поля с кнопками**: клик в любом месте label «нажимает» первую кнопку внутри (так `NokiNumberInput` уменьшал время от любого тапа). Корень таких полей — `div`, подпись — `<label for>`.
- vue-scroll-picker: клик по варианту не выбирает его, только прокрутка колёсиком/перетаскивание.
- **Тесты в браузере-панели**: `requestAnimationFrame` и переходы почти стоят, пока панель не на экране. Тур ждёт конца прокрутки по кадрам — проверять ожиданием в скрипте (`waitFor`), а не фиксированной паузой. Скриншоты при эмуляции высокого телефона рисуют фиксированные элементы не на месте — проверять `getBoundingClientRect` / `elementFromPoint`.
- **Программный `.click()`** — не жест пользователя: буфер обмена («Скопировать») падает с ошибкой. Проверять настоящим кликом.
- **Sortable (DnD)** завершает перетаскивание по `mouseup`/`touchend`, не по `pointerup` — синтетический тест должен слать их, иначе копия карточки «зависает».
- **Git Bash** превращает `/noki/` в путь Windows в переменных окружения — `MSYS_NO_PATHCONV=1`.
- **`window.confirm`** в режиме просмотра блокирует панель — в тестах подменять заглушкой.
